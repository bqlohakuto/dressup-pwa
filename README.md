# Dress Atelier Prototype

スマホ向けフォトリアル着せ替えゲームの操作試作です。

## v0.2 実装済み
- 成人女性4モデルの選択UI
- 正面 / 背面切替
- 3ポーズ選択
- インナー / トップス / ボトムス / ワンピース / アウター / 靴 / バッグ / アクセサリー
- 衣装カテゴリごとの独立レイヤー表示
- トップスの下にインナーを保持するレイヤード
- ワンピース着用時のトップス・ボトムス自動非表示
- カテゴリごとのカラー保持
- カテゴリごとの素材設定
- ピンチズーム / ドラッグ / ダブルタップ全身復帰
- コーデ端末保存
- 撮影モード
- PWA / オフラインキャッシュ

## 素材方針
最終素材は 1440×2560 を基準に、透過 WebP を基本、必要箇所のみ PNG とする予定です。
現在の公開版は衣装レイヤー構造と操作感を先に検証するため、フォトリアル人物画像の上に軽量なベクターレイヤーを合成しています。
衣装IDとレイヤー構造は、後から同一座標の透過WebPへ差し替えられる設計です。
